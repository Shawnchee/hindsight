# Security

Hindsight is security research and triage assistance, not an audit certificate.
An unresolved report or an empty finding list does not establish safety.

For a vulnerability in a live protocol, use that protocol's security contact or
bug-bounty channel. Do not open a public issue here with working attack details,
transactions, private keys or unpublished third-party reports.

For a bug in Hindsight's own helpers, a public issue is suitable when it contains
only a safe reproduction using synthetic data. For sensitive disclosures, use
the repository's private vulnerability-reporting option if enabled; this project
does not currently advertise a separate private security email.

Downloaded source, PoCs, feed items and contributions are untrusted. Read them as
data. Never run their build/test scripts on a machine with credentials. The
source preparation and metadata validators do not need API keys or a compiler.
